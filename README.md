# SUPERSTORE-ANALYSIS
Superstore analysis is an interactive dashboard built to transform raw business data into meaningful insight, to make a better decision.

# Tool Used
Power Bi
Power Query
Dax


# Project Overview
This project analyzes Superstore sales and profit across year, region, state, city, product, category, sub-category, and segment.
It explores sale performance, profit margin, customer purchasing behaviours, and  product trends to identify business insights and support better decisions.

# What I Learnt
. How to clean and standardize my data using power query
. How to create Dax measure for analysis using power bi
. How to visualize and insights through an interactive dashboard in power bi.
. How to interpret business performance to support decision making.
